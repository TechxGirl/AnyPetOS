# PetPassport Workspace Module Visual Polish v1 Pack

This pack makes all role module pages feel less squished and more like premium command boards.

## What this improves

- More breathing room on every role module page
- Sleeker module hero sections
- Wider action cards
- Better spacing inside top feature/action cards
- Less cramped quick-action buttons
- Cleaner workflow board lanes
- Better empty states
- More polished pipeline snapshot cards
- Responsive spacing for smaller screens

## Install

1. Stop Vite with Ctrl + C.
2. Extract this zip.
3. Copy these into your real `pet-passport` folder:
   - `src`
   - `public`
   - `package.json`
   - `package-lock.json`
   - `vite.config.js`
   - `index.html`
4. Choose Replace when Windows asks.
5. Run:

```powershell
npm install
npm run build
npm run dev -- --host
```
