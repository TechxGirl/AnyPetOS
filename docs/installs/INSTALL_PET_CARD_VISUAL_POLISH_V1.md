# PetPassport Pet Card Visual Polish v1 Pack

This pack makes the animal cards look cleaner, wider, more premium, and closer to the approved PetPassport concept.

## What this improves

- Wider photo-first animal cards
- Cleaner real pet photo display
- Better no-photo placeholder
- Smaller, sleeker status pill
- Favorite/save button moved over the photo
- Cleaner pet identity section
- Better species/sex/morph/last-fed tiles
- Food list shown as clean pills
- No more squished/truncated action buttons
- Full-width Open Passport button
- Better hover polish
- Light/dark mode compatibility

## Install

1. Stop Vite with Ctrl + C.
2. Extract this zip.
3. Copy these into your real `pet-passport` folder:
   - `src`
   - `public`
   - `package.json`
   - `package-lock.json`
   - `vite.config.js`
   - `index.html`
4. Choose Replace when Windows asks.
5. Run:

```powershell
npm install
npm run build
npm run dev -- --host
```
