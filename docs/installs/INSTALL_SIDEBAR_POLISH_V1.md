# PetPassport Sidebar Polish v1 Pack

This pack cleans up the left sidebar so it looks closer to the premium concept mockup.

## What this fixes

- Workspace card no longer wraps awkwardly
- “1 enabled” is now shown as a clean subtitle
- PetPassport brand area is cleaner
- Sidebar spacing is more premium
- Active navigation items look more polished
- Workspace accent color is applied more consistently
- Footer gets a cleaner theme toggle and user card
- Scrollbar is less visually loud
- Sidebar width is slightly widened so labels have room to breathe

## Install

1. Stop Vite with Ctrl + C.
2. Extract this zip.
3. Copy these into your real `pet-passport` folder:
   - `src`
   - `public`
   - `package.json`
   - `package-lock.json`
   - `vite.config.js`
   - `index.html`
4. Choose Replace when Windows asks.
5. Run:

```powershell
npm install
npm run build
npm run dev -- --host
```

## Test

1. Open Owner workspace.
2. Check the sidebar top area.
3. Switch to Breeder, Rescue, Vet, Education/Zoo, Sitter, and Retail.
4. Confirm the sidebar accent color changes.
5. Confirm workspace text does not wrap weirdly.
6. Confirm mobile menu still opens/closes.
