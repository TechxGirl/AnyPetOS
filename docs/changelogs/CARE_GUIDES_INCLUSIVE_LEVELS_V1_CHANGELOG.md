# Care Guides Inclusive Levels v1 Changelog

## Added

- `CARE_LEVELS` export: Beginner, Intermediate, Advanced.
- Care level filter in the Care Guides toolbar.
- Care level chip strip with counts.
- More inclusive group-aware starter guides for invertebrates and arachnids.
- Custom/unknown animal starter guide.

## Updated

- Care Guide card layout to prevent cramped text.
- Care Guide metric tiles now use responsive auto-fit sizing.
- Difficulty label renamed to Care level.
- Existing "Beginner-intermediate" and "Species-dependent" values normalized to clear care levels.
- Care guide policy note updated to explicitly mention invertebrates.

## Preserved

- Smart feeding options.
- Custom food support.
- Feeding result tracking.
- Care guide search.
- Verified/fallback labels.
- Share/transfer/photo/workspace features.
