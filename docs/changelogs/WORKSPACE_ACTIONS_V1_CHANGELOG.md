# Workspace Actions v1 Changelog

## Added

- Functional workspace module pages
- Real action buttons on module cards
- Quick action templates per module
- Module record creation form
- Animal assignment to module records
- Module-specific type/status fields
- Priority and due date fields
- Notes field
- Kanban-style status lanes
- Complete / reopen / delete actions
- Module CSV export
- Data Center navigation from module pages
- Add Animal navigation from module pages

## Module coverage

This pack adds working beta actions for the major workspace module pages, including:

- Owner: Care Planner, Health Watch, Sitter Access
- Breeder: Pairings, Hatchlings, Sales, Transfers, Expo Mode
- Rescue: Intake, Quarantine, Rehab Plans, Adoptions, Foster Care
- Veterinary: Appointments, Treatment Notes, Medical History, Shared Passports
- Education/Zoo: Ambassador Animals, Programs, Exhibits, Public Profiles
- Pet Sitter: Visits, Care Reports, Client Animals, Emergency Plans
- Retail/Pet Shop: Inventory, Supplier Records, Customer Transfers

## Notes

Records are currently local beta workflow records. The next backend step is creating Supabase tables for professional workflow records and permissions.
