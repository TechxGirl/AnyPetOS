# Expo Command Center v1 Changelog

## Community Expo Discovery

- Public pre-show expo feed inside Community.
- Public expos for breeders, rescues, educators, zoos, retailers, and mixed events.
- Search and event-type filtering.
- Cloud-synced following for signed-in users.
- Device-based following for anonymous visitors.
- Featured animal previews show price, exhibitor, booth, and listing code.
- Featured previews open the exact public animal listing.
- Public update log for inventory, status, booth, schedule, and announcements.

## Organizer and exhibitor system

- Event creation and management.
- Draft, Published, Live, Completed, and Archived statuses.
- Venue, location, dates, hours, branding, contacts, and description.
- Public inventory release date.
- Optional public-link expiration.
- Event public-link regeneration.
- Exhibitor access requests and organizer approval.
- Multiple exhibitor types.
- Security guard prevents exhibitors from approving themselves.

## Planned animal inventory

- Add existing cloud-synced PetPassport animals.
- Real uploaded animal photos.
- Price/adoption fee, deposit, negotiable, featured, availability, and catalog controls.
- Booth/enclosure location.
- Temperament, feeding, weight, care level, genetics, lineage, parents, supplies, pickup requirements, and public Expo notes.
- Unique listing token and human-friendly lookup code.
- Listing-link regeneration.

## Public Expo Catalog

- No login required.
- Search animal, species, morph, breed, exhibitor, booth, or listing code.
- Filter by species, availability, exhibitor, and price.
- Save animals.
- Compare up to three.
- Large booth lookup card.
- Secure public snapshots exclude private owner and health data.

## My Expo Plan

- Saved animals become a personal booth route.
- Route sorts by booth.
- Shows exhibitor, listing code, and route order.
- Estimated budget when prices are public.
- Anonymous device storage and signed-in cloud favorites.

## QR and link system

- Event QR.
- Individual animal QR.
- Exhibitor/business QR.
- Care-guide QR.
- Kiosk QR.
- Private ownership-transfer QR.
- Copy, preview, regenerate, and print workflows.

## Kiosk Mode

- Touch-friendly full-screen catalog.
- Search, filters, saved animals, compare, booth lookup, and interest forms.
- 15-second public refresh.
- Automatic inactivity reset.
- Visitor personal details clear on reset.
- Optional PIN-controlled exit.

## Leads, holds, and completion

- Public interest form with contact consent.
- Lead pipeline statuses.
- Internal notes and CSV export.
- Temporary holds with expiration.
- Deposits and manual payment status.
- Release, Sold, and Adopted completion.
- Private Passport transfer launch.

## Print Center

- Cage cards.
- QR labels.
- Event catalog.
- Care cards.
- Staff checklist.
- Select listings or print all.

## Analytics and after-event tools

- Event and animal scans.
- Followers, favorites, leads, holds, and completed outcomes.
- Most-viewed and most-saved listings.
- Event duplication, archive, export, and follow-up report.

## Security and data integrity

- Row Level Security for all Expo tables.
- Organizer and approved-exhibitor boundaries.
- Exhibitors cannot approve themselves.
- Listing ownership must match PetPassport ownership and exhibitor membership.
- Holds must match event, listing, vendor, and lead.
- Follow/favorite writes are limited to active public expos.
- Public RPCs expose curated fields only.
- Security-definer execution is restricted to intended roles.
- Sequence grants are limited to Expo tables.
