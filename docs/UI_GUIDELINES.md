# 🐍 PetPassport

**Document:** UI Guidelines  
**Version:** 1.0  
**Last Updated:** July 2026  
**Status:** Living Document

---

# 🎨 Design Philosophy

PetPassport should feel:

- Modern
- Clean
- Friendly
- Professional
- Calm
- Fast

The interface should reduce stress, never create it.

---

# 🧭 Navigation

Users should never be more than three clicks away from the feature they need.

Navigation should remain simple regardless of account type.

---

# 🐾 Terminology

Preferred terms:

- Passport
- Collection
- Timeline
- Transfer
- Workspace (Future)
- Dashboard
- Care Log

Avoid:

- Profile
- Record
- File
- Entry
- Folder

Our terminology should reinforce the Passport brand.

---

# 📱 Dashboard Philosophy

Every dashboard should answer one question:

**"What should I do next?"**

Examples:

- Feedings due
- Medications due
- Recent activity
- Upcoming reminders
- Animals needing attention

Never show an empty dashboard.

---

# 🚀 Onboarding

The first experience should be exciting.

Every onboarding screen should answer one question:

- Why am I here?
- Who am I?
- What experience fits me?
- Why should I be excited?
- What should I do next?

Users should finish onboarding wanting to create their first passport immediately.

---

# 🛂 Passport Experience

Everything revolves around the Passport.

Actions should use Passport terminology whenever possible.

Examples:

- Create Passport
- Passport Timeline
- Passport Transfer
- Passport History
- Passport QR

---

# 🎉 Success Moments

Celebrate meaningful milestones.

Examples:

- First Passport Created
- 100 Care Logs
- First Passport Transfer
- Birthday
- Adoption Anniversary
- Recovery Milestones

Small celebrations create memorable experiences.

---

# 📝 Empty States

Never display:

"No Data"

Instead:

Explain the feature.

Show why it matters.

Guide users toward the next action.

---

# ⚡ Speed

The most common actions should require the fewest taps.

Examples:

- Feed
- Water
- Medication
- Weight
- Shed
- Note

Logging care should take seconds.

---

# ♿ Accessibility

- Large touch targets
- High contrast
- Readable fonts
- Clear icons
- Color should never be the only indicator
- Mobile-first design

---

# 💚 Emotional Design

We are not building software.

We are helping people care for animals they love.

Every interaction should leave the user feeling:

- Organized
- Confident
- Supported
- Excited

PetPassport should feel like a trusted companion, not just another app.
